# Seoul Energy Simulation Data Analysis

Energy generation pattern analysis and machine learning forecasting using Seoul Energy Simulation Data.

## Results

* Analyzed 17 VPPs and 97 energy resources
* Identified yearly, monthly, and hourly generation patterns
* Detected high-performing and underutilized resources
* Evaluated operational risks and resource concentration
* Developed machine learning models for generation forecasting
